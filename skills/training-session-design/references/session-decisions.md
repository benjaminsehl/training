# Session decisions

## Substitution workflow

Preserve the original exercise's main purpose, then compare target muscle, joint action, loading position, stability, available range, fatigue and setup. A pressdown replaced by close-grip bench changes systemic demand and chest work; a Nordic is not a dose-equivalent swap for a leg curl. Re-establish load/effort rather than transferring kilograms or app settings. Keep aliases tied to distinct variations when leverage, assistance or range changes.

For travel/bodyweight, obtain actual equipment and safe anchor/support options. Choose a scalable variation, document leverage/assistance/range, and leave a measurable next step. Do not promise a home device is available or invent its safe mounting arrangement. Calisthenics strength work and skill practice have different endpoints; do not turn a technical practice set into a failure test.

Exercise libraries supply candidates rather than universal biomechanics. Avoid copying every cue or forcing a prescribed joint angle onto everyone.

For flexibility, stretching timing or yoga practice, use [training-mobility-yoga](../../training-mobility-yoga/SKILL.md).

## Warm-up and work allocation

Use familiar preparation and exercise-specific ramping to check execution and readiness without counting it as hard training volume. The needed preparation depends on the lift, load, prior work and user's response. Exact warm-up minute counts require a practical reason rather than a universal timer.

## Short session mode

Identify whether the real bottleneck is excess optional work, setup, rest drift or an unrealistic target. Keep priority technical work separate initially. Antagonist/less-competing accessory pairs can use one muscle's recovery for another exercise, while preserving recovery before repeating the same task. Same-muscle supersets can compromise output. If clean reps/effort worsen, restore recovery or unpair; no evidence-backed universal percentage cutoff is supplied. Use the [reviewed rest evidence](../../../evidence/2026-10-12-rest-recovery-time-efficiency.md).

## Effort and endpoint

Use explicit current targets; a historical plan's RIR is not today's confirmed prescription. If drafting new targets, explain them as a proposal reflecting training experience, exercise safety, total work and goal. The [failure review](../../../evidence/2026-10-05-failure-rir.md) does not justify compulsory failure for every accessory. An intended technical max ends with the last acceptable rep, not loss of control. Advanced methods need a specific reason and separately reviewed dose, not automatic addition when time is short.

## Useful output

For each exercise: purpose, variation/setup, warm-up versus work, reps/load selection, effort, rest, time budget, backup. Log actual load/units, clean reps, explicit effort, setup/ROM differences and symptoms. If a key fact is missing, give a conditional branch and the single fact needed to choose it rather than a falsely precise workout.

# Progression decisions

## Reconcile before calculating

Use [record interpretation guidance](../../references/context-and-evidence.md). Match session date/timezone, actual exercise variation, loading unit, per-hand versus total convention, assistance, device mode, unilateral records, set purpose and completion. Preserve raw values and unknown fields. Only derive volume load or PRs from a compatible explicit definition. A new exercise or changed range of motion needs a new comparison baseline.

Synthetic example: a session labeled completed contains only skipped preparation records. That is unresolved performance evidence. A different session mixes work sets, warm-ups and mobility records without effort data; its row count is not a confirmed hard-set count. Ask for or retrieve the missing performed work; do not mark the user absent, declare progress, or add a blanket percentage.

## Pick a decision

- **Progress within the current rule:** target reps achieved with comparable technique, range and intended effort. Increase the specified lever. For double progression, build reps within the agreed band, then use a feasible small load step when the agreed sets satisfy the criterion. Exact increments and repeat counts are individualized proposals, not scientific constants.
- **Repeat:** performance remains in range and data do not justify a change. A single exposure at the top does not establish every later set met the target. Avoid treating repetition as failure.
- **Adjust today's demand:** reported readiness or clean execution materially differs. Choose a workable load/rep endpoint for the intended stimulus; preserve the broader block unless the pattern persists. Do not insist on a percentage-based target regardless of symptoms or execution.
- **Investigate a plateau:** repeated comparable exposures show stalled or declining performance. Check adherence evidence, exercise/setup changes, rest, execution, effort, total lifting/conditioning demand and reported recovery. Decide whether skill, dose, fatigue or measurement is the likely constraint; name uncertainty.
- **Change volume:** only after understanding current actual exposure and bottleneck. More sets are not the default response to insufficient effort, poor records or accumulating fatigue. Record direct/indirect counting and reassess the affected work before increasing everything.

## Effort and fatigue

[Autoregulation evidence](../../references/source-checks-2026-10-12.md) supports flexibility without demonstrating a uniquely optimal progression algorithm for hypertrophy. An explicit RIR report is an estimate; the schema and the user's calibration matter. A higher-rep result produced by shortened range or extra effort is not unqualified improvement. Better controlled range can itself be useful, but describe the changed task.

The [failure review](../../../evidence/2026-10-05-failure-rir.md) opposes compulsory failure as a blanket inference. Program-specific tactical failure and a technical-max test need separate interpretation. Soreness is not a required success metric; sleep, soreness and motivation reports contextualize performance rather than diagnose a physiological state.

For suspected accumulated fatigue, propose the smallest justified reduction in stress and a reassessment condition. Fixed deload timing or percentage reductions have not been established as universal rules by this evidence review. Pain or illness is not a normal progression problem to solve by pushing through.

## Useful output

A compact per-exercise entry: comparable completed work → interpretation and confidence → next target/rule → fallback → required log fields. Distinguish a conditional recommendation from a confirmed load prescription when raw data or equipment increments are missing. Do not alter an active training-system plan, session or authentication state through this skill alone.

# Review training and progress deliberately

Read [context and evidence](../references/context-and-evidence.md), then follow [record reconciliation and decisions](references/progression-decisions.md).

1. Identify the exact exercise, prescription and comparable exposures. Separate actual completed work from planned, skipped, warm-up or ambiguous rows.
2. State what the data can establish. Unknown effort, units or execution prevents claims depending on those fields; it does not erase all valid observations.
3. Compare clean reps/load at similar execution and intended effort. Select progress, repeat, reduce demand, or gather missing information. Use the current program's progression rule when verified; otherwise propose a rule rather than claim one is active.
4. Change one interpretable lever when possible. Explain the trigger, available increment, fallback if it overshoots, and observation needed at the next exposure.
5. Investigate a repeated decline across context before blaming volume or prescribing a deload. Missing logs and one difficult day do not establish a plateau.

Return: observed performance, data gaps, per-exercise recommendation, rationale, and next log fields. Separate advice from writes. Never infer RIR from app percentages or increase every load merely because a session is marked completed.

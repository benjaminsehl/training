# Training coaching skills

Reusable, evidence-linked workflows. They produce coaching advice and reviewable plans; they do not authorize training-account writes or authentication changes. Personal plans, logs and health details belong in private systems, not this public repository.

## Choose a skill

- [Design a session](training-session-design/SKILL.md): one workout, substitutions, equipment and time constraints.
- [Design a program](training-program-design/SKILL.md): program types, full-body/upper-lower/PPL splits, variable schedules and block structure. Hypertrophy, strength, maintenance and minimal-equipment modes share this workflow.
- [Review progression](training-progression-review/SKILL.md): completed-set reconciliation, load/repetition/volume decisions, plateaus and effort.
- [Integrate conditioning and recovery](training-conditioning-recovery/SKILL.md): hybrid scheduling, interval-dose interpretation and demand management.
- [Plan mobility, stretching and yoga](training-mobility-yoga/SKILL.md): movement goals, stretching timing and appropriately scoped yoga practice.

Read only the selected skill and its relevant references. Shared [context contract](references/context-and-evidence.md) keeps current facts, evidence and proposed decisions separate. Preserve the repository-relative `skills/` and `evidence/` layout when packaging; copying an individual folder alone omits shared references. These files are ready to use as a repository skill library; installation into a particular assistant's discovery system is a separate step.

## Evidence coverage

The initial release directly checks weekly volume/frequency, load autoregulation, concurrent training and the HIIT duration model in [source checks](references/source-checks-2026-10-12.md). It also uses the repository's dated failure/RIR and rest-efficiency reviews. Mobility has its own source review. Check the stated population, study type, review depth and uncertainty before applying a finding.

Not settled here: an individual's optimal weekly sets, exact progression percentage or deload schedule, device-specific eccentric settings, advanced intensity methods, BFR, lengthened-partial prescriptions, clinical rehabilitation, and exact commercial-program reproduction. These gaps are not permission to invent numerical rules. Add a source-reviewed reference when a concrete coaching decision needs one.

## Validation

See [validation record](VALIDATION.md) for structural checks and realistic behavior tests. Passing examples supports usability; it does not validate individualized exercise prescriptions or prove the skills improve outcomes.

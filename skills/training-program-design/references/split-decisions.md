# Split decisions

These are coaching design heuristics, not evidence of one universally superior split. [Reviewed dose/frequency evidence](../../references/source-checks-2026-10-12.md) differentiates muscle growth from strength outcomes and does not identify a personalized optimum.

## Choose by the schedule that actually happens

- Few reliable weekly opportunities: full-body can protect broad coverage if a session is missed. Check whether session length and fatigue permit the planned work.
- A stable upper/lower rotation: retain it when it is working. With a variable three/four-day schedule, a rolling sequence can preserve order without cramming a missed session or resetting every Monday. Assess coverage across the whole rotation, not one calendar week.
- PPL or body-part emphasis: useful when distribution and preference justify it, but test what happens when one day disappears. Lower attendance can lengthen gaps between exposures; do not infer that the split label itself prevents growth.
- More frequent short sessions: redistribute existing work first. More training days do not automatically mean more recoverable volume.

Illustration: for three reliably available days and an occasional fourth, compare a three-day full-body base with an optional short priority session against a rolling upper/lower sequence. Choose based on current plan continuity, session length and preference. Neither demands inventing a fourth guaranteed day.

## Allocate and audit

List intended targets for each exercise; distinguish direct work from secondary involvement. State any counting convention and avoid counting warm-ups, incomplete records or both sides as duplicated whole-body sets. A fractional model can be useful analytically, but no exact indirect-set fraction is universal physiology.

Check whether later work remains productive at intended effort, whether the next session repeats stressed structures, and whether the user can complete transitions within available time. For a priority muscle, redistribute effort before raising every muscle's volume. Any extra sets need a hypothesis and a review criterion, not merely the absence of soreness.

When adapting a named book or commercial program, obtain its exact source if fidelity matters. Do not present reconstructed tables or unverified page anchors as the original program.

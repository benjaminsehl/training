# Design priorities

Use this as a diagnostic order, not as a universal ranking of physiological importance. Move to later details only after earlier constraints are sufficiently clear for the decision at hand.

## 1. Define the outcome and feasible context

Name the outcome: growth, strength on a specific task, maintenance, skill practice, conditioning support or a mixed priority. Establish schedule, equipment, time, restrictions and recent completed training. A theoretically strong plan that is not repeatable is not yet a useful design.

## 2. Make execution interpretable

Choose exercises and standards that can be performed tolerably and compared over time. Define range, setup, load convention and what counts as a completed repetition. Technique does not need to be identical between people, but changing the task makes progression harder to interpret.

## 3. Assign exercises clear roles

Select movements for the required target or task, practical fit, loading options and fatigue cost. Cover priorities before adding variety. A substitution should preserve the relevant role or clearly state what changes; a shared muscle label alone does not make two exercises equivalent.

## 4. Set effort and progression rules

Specify work-set effort, safe stopping boundaries and the evidence required to progress. [Reviewed failure evidence](../../../evidence/2026-10-05-failure-rir.md) does not require every set to reach failure, and [reviewed autoregulation evidence](../../references/source-checks-2026-10-12.md) does not establish one uniquely optimal progression algorithm. Preserve comparable execution before treating more load or repetitions as progress.

## 5. Set dose and distribution

Start from completed, recoverable work when available; otherwise use a conservative trial with a review point. Distribute work across the schedule so priority sets remain productive. Frequency is a way to arrange exposure, not proof of a superior split, and the individual's best weekly dose remains an [open research question](../../../questions/README.md).

## 6. Optimize time and secondary methods

Only then refine rest structure, exercise pairing, advanced set methods, periodization and optional variety. The [rest and time-efficiency review](../../../evidence/2026-10-12-rest-recovery-time-efficiency.md) supports some time-saving pairings without establishing universal rest ceilings or equivalent outcomes in every context. Add complexity only when it solves a named problem and define how its effect will be reviewed.

## When the order can change

Safety, symptoms, competition dates, clinical restrictions or a specific skill test can move a later concern to the front. State the reason. This workflow organizes decisions; it does not convert historical summaries into verified rules or activate a program without authorization.

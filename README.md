# training

An open, source-linked training research project and reusable coaching-skill library. Covers workout design, program types and splits, progressive overload, conditioning and recovery, mobility, stretching and yoga.

## Start here

- [Coaching skills](skills/README.md): reusable decision workflows and references
- [Research library](research/README.md): dated, generalized summaries of the historical research collection
- [Reviewed evidence](evidence/README.md): source checks with findings and limitations
- [Open questions](questions/README.md): uncertainties worth resolving next
- [Contribute](CONTRIBUTING.md): add research or improve a skill from any computer

## How to read the evidence

Historical summaries in `research/` are context, not independently reverified conclusions. Their original dates do not establish current accuracy. Recent source reviews in `evidence/` and `skills/references/` state what was actually checked. A skill turns evidence into a configurable workflow; it is not an automatically approved personal program.

Distinguish study findings, uncertainty, coaching interpretation and individual decisions. Repeated summaries of the same study are not independent evidence. Preprints are provisional, and an abstract-only review is not a full methods audit.

## Work from anywhere

Edit Markdown directly on GitHub, or clone the repository:

```sh
git clone https://github.com/benjaminsehl/training.git
cd training
```

No application dependencies or imported scripts are needed. Add a review with [the evidence template](templates/evidence-review.md), link it from the appropriate index, and open a pull request for substantial changes.

## Public scope

This public collection contains generalized research and reusable coaching methods. Personal workout logs, physiological records, account profiles, equipment inventories, program snapshots, credentials and private operational notes are excluded. Public summaries are editorial adaptations, not byte-identical archival originals. See [provenance and scope](provenance/README.md).

Source papers, books and commercial programs retain their own rights. This project links to them rather than redistributing their full text or proprietary program material. No license has been selected for this repository.

Research supports informed decisions; it does not replace appropriate medical assessment, individualized screening or consent to change a training plan.

# Provenance and public scope

Prepared October 12, 2026 from a historical training-research collection dated September 25, later dated source reviews and newly distilled coaching skills.

## Editorial layers

- `research/`: generalized summaries of historical research notes, retaining source citations and dates. These are adapted public versions, not byte-identical originals or newly verified scientific conclusions.
- `evidence/`: generalized versions of dated source reviews. Personal application and private operational context were removed; source-check limitations remain explicit.
- `skills/`: reusable coaching workflows with configurable goals and current-context checks. Dated reference notes distinguish source evidence from interpretation.

## Intentionally excluded

Personal workout logs and physiological records; account/profile exports; personal equipment inventories; individual program snapshots and prescriptions; authentication/configuration material; private operational notes; executable imports, caches and duplicate archives; original commercial books/program files and other third-party full-text material.

The original private collection is unchanged. Public repository history begins with the public-safe edition only. No private archive, personal record or credential is needed to use or contribute to this project.

Source citations identify underlying publications, whose rights and access restrictions remain their own. No repository license has been selected.
